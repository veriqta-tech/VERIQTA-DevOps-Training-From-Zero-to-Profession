# Day 001 independent practical assessment

**Goal:** Demonstrate that you can create directories, create a file, rename it, write to it, and verify the result without a step-by-step command script.

## Task

In `~/devops-training/01-linux`, create a `practice` directory. Inside it, create `day-001.md` and rename it to `day-001-report.txt`. Write this **exact sentence** into the renamed file:

```text
Linux Day 1 practical assessment completed.
```

Use `cat` to verify the exact text and `tree` to verify the folder structure. Do not remove your notes.

## Expected relevant structure

```text
01-linux/
├── notes/
│   └── day-001.md
└── practice/
    └── day-001-report.txt
```
