# Day 001 knowledge check

## Question 1
What is the difference between `mkdir` and `touch`?

A. `mkdir` creates directories, while `touch` can create empty files.  
B. Both commands only delete files.  
C. `mkdir` displays file contents, while `touch` changes directories.  
D. They are interchangeable commands.

**Answer:** A.

**Explanation:** `mkdir` creates directories. `touch` creates a missing file as an empty file or updates timestamps for an existing file. It does not overwrite the file's contents.
