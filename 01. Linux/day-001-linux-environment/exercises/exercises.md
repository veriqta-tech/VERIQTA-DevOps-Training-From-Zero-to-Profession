# Day 001 practice exercises

Do these after the guided lab. These are learning exercises, not claims about what the original learner completed.

1. Run `whoami`, `pwd`, and `hostname`. In your own words, explain each output.
2. Run `ls /` and identify three system directories. Do not modify them.
3. From your home directory, use `cd ~/devops-training/01-linux` and then `pwd`. What path appears?
4. Create a file called `notes/my-observations.md` with `touch`. Use `echo "Today I learned Linux basics" > notes/my-observations.md` and verify with `cat`.
5. Run `tree ~/devops-training/01-linux`. Confirm both note files are present.
6. Predict what `echo "Changed" > notes/my-observations.md` would do. **Do not run it** until you understand that `>` replaces the file contents.

## Self-check

- Did every command run successfully?
- Did you verify the file content, not just its filename?
- Can you explain the purpose of every command without looking at the answer?
