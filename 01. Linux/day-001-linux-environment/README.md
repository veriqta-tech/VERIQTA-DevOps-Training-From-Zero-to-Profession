**Lab platform used by the original learner:** Ubuntu 26.04 LTS on an AWS EC2 instance, accessed through a terminal on a Mac.

## Learning outcomes
After this lesson, you should be able to identify your Linux operating system, user, current directory, and hostname; recognize major Linux filesystem directories; create a training workspace; create and read a text file; inspect a directory tree; and troubleshoot a missing utility.

## Before you begin
You need an accessible Linux terminal. An existing Ubuntu machine or a safely provisioned Ubuntu VM is sufficient. AWS EC2 is optional. If you use EC2, cloud resources can incur charges. Use your own instance, follow your organization's access rules, and do not publish private keys, IP addresses, or credentials in screenshots.

This lesson does **not** require a root shell. Only package installation uses `sudo` when necessary.
