## Knowledge check

Try each question before looking at the answer.

**Q1.** Which command preserves `app.conf` and creates a backup?

A. `mv app.conf app.conf.backup`  
B. `cp app.conf app.conf.backup`  
C. `rm app.conf`  
D. `mkdir app.conf.backup`

**Q2.** Which command moves up one directory?

A. `cd /`  
B. `cd ..`  
C. `cd ~`  
D. `pwd`

**Q3.** Which command requests confirmation before removing `test.log`?

A. `rm test.log`  
B. `mv test.log`  
C. `rm -i test.log`  
D. `cp test.log`

### Answer key and explanation

1. **B.** `cp` makes a copy while preserving the original.
2. **B.** `cd ..` moves to the parent directory.
3. **C.** `rm -i` requests confirmation before removal.

**Verified learner result:** 3/3 correct. The knowledge check tests foundational concepts; it is not a professional certification.
