## Setup

Use an Ubuntu terminal or another Linux environment with Bash, `cat`, `less`, `head`, `tail`, `grep`, `wc`, `sort`, `uniq`, `cmp`, `sha256sum`, and a text editor. `tree` is optional; if it is unavailable, use `find`. Before running any setup script, read it first. The practice-file script at [setup/prepare-practice-files.sh](setup/prepare-practice-files.sh) is designed not to overwrite existing files.

Use a disposable training directory and never run practice redirection commands against actual production logs or irreplaceable evidence.

## Learning sequence

For every stage: **read → predict → execute → inspect → verify → explain**. Save your own terminal screenshots at verification checkpoints if your instructor requests them. Example outputs and diagrams in this repository are instructional illustrations, not records of a particular student's session.

## Completion requirements

Complete the six foundational guided labs, the incident project, the exercises and assessments; verify evidence hashes and keep original evidence unchanged. Report observed facts separately from unconfirmed root-cause hypotheses.

Work through the materials in order. The instructor performs publication checks separately; students only need the learning resources.
