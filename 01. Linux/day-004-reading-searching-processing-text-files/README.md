## Setup (do not overwrite your work)

Use an Ubuntu terminal or Linux VM with `bash`, `grep`, `sort`, `uniq`, `sha256sum`, `cmp`, `vi`, and `tree` (install `tree` if needed). To create the *practice* files, inspect and run `setup/prepare-practice-files.sh`; it refuses to overwrite existing files. Project evidence is synthetic and must be kept separate from real production data.

## Classroom approach

Read the explanation, predict the output, run **one command at a time**, compare expected results, and proceed only when the checkpoint passes. When you reach the incident project, preserve source evidence unchanged and distinguish observation from hypothesis.
